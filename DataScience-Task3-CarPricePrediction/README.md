# Car Price Prediction with Machine Learning

## Objective

Build a machine learning model to predict the selling price of used cars
based on different features of the car.

## Dataset

Vehicle Dataset from CarDekho.

## Features Used

- Present Price
- Kms Driven
- Car Age
- Fuel Type
- Seller Type
- Transmission
- Owner
- Brand

## Models Used

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Files

- `car data.csv` - Dataset
- `car_price_prediction.ipynb` - Jupyter Notebook
- `car_price_model.pkl` - Trained model
