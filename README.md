# OIBSIP — Data Science Internship Projects

This repository contains the projects I completed during my Data Science internship at Oasis Infobyte.

## Projects

### Task 1: Iris Flower Classification

A machine learning classification project that predicts the species of an iris flower using sepal and petal measurements.

**Key work:**
- Exploratory Data Analysis (EDA)
- Data visualization using pairplots and boxplots
- Training and evaluation of classification models
- Confusion matrix and classification report
- Model comparison and prediction

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

[View Task 1](./DataScience-Task1-IrisFlowerClassification/)

### Task 2: Car Price Prediction

A machine learning regression project that predicts used-car selling prices using car age, present price, mileage, fuel type, transmission, and other features.

**Key work:**
- Data cleaning and feature engineering
- Exploratory Data Analysis and correlation heatmap
- Training Linear Regression, Random Forest, and Gradient Boosting models
- Evaluation using MAE, RMSE, and R² score
- Feature importance analysis

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

[View Task 2](./DataScience-Task2-CarPricePrediction/)

### Task 3: Sales Prediction Using Python

A machine learning regression project that predicts product sales based on advertising expenditure across TV, Radio, and Newspaper.

**Key work:**
- Exploratory Data Analysis and pairplot
- Scatter plots and correlation heatmap
- Training Linear Regression and Random Forest models
- Evaluation using MAE, RMSE, and R² score
- Residual analysis and advertising-channel importance

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

[View Task 3](./DataScience-Task3-SalesPrediction/)
